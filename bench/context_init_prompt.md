Please set up this repository for future coding-agent sessions by writing a file named AGENTS.md at the repository root.

Future sessions will start with no memory of this one. They will read AGENTS.md first and then work on a change, such as fixing a reported bug, in this same environment. Write down what they would otherwise have to work out for themselves.

Before you write anything, explore:

1. The repository: its layout, where the source code lives, where the tests live and how they are organised, and the files that describe how the project is developed (contributor guides, configuration, the changelog).
2. The environment you are in: which Python and which tools are installed, and how to run the tests here. Run the commands you plan to recommend and check that they work in this environment; do not install anything.

Then write AGENTS.md. Keep it concise: a short file that a session can read in a minute is worth more than a complete one. Cover:

- how to run the tests here, including how to run a single test file or a single test, with commands you have checked;
- the layout, in a few lines: where the code for each part lives and where its tests go;
- the conventions that matter when making a change: coding style, how tests are usually written in this project, and anything else a change is expected to include.

Write only commands that work in this environment, and say nothing you have not checked. Do not change any other file. Leave AGENTS.md in the working tree at the repository root when you finish.
